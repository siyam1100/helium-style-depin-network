# Decentralized Physical Infrastructure (Helium-style)

A professional-grade implementation for decentralized wireless networks. This repository solves the "Capital Expenditure" problem of traditional telcos. Instead of one company building all the towers, thousands of individuals deploy "Hotspots" (IoT gateways). In exchange for providing verifiable coverage and relaying device data, they earn protocol rewards.

## Core Features
* **Proof-of-Coverage (PoC):** Logic to verify that Hotspots are actually where they claim to be and are providing a signal.
* **Data Credits (DC):** A stable internal utility token used to pay for data transfer, generated by burning the native volatile token.
* **Device Registry:** An on-chain mapping of unique hardware IDs to their geographic coordinates (H3 hexagonal grid).
* **Flat Architecture:** Single-directory layout for the Hotspot Registry, Reward Engine, and Token Treasury.

## Logic Flow
1. **Onboard:** A user buys a gateway and registers its location on-chain by staking tokens.
2. **Challenge:** The network periodically "Challenges" the Hotspot to prove its radio frequency (RF) presence.
3. **Transfer:** An IoT sensor (e.g., a smart water meter) sends data through the Hotspot.
4. **Reward:** The contract calculates the "Coverage Score" and mints rewards to the Hotspot owner.

## Setup
1. `npm install`
2. Deploy `HotspotRegistry.sol` and `DePINRewards.sol`.
